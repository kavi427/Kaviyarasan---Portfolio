Automated Sales Analytics Dashboard
Python • MySQL • Pandas • Matplotlib • Schedule
Project Overview
This project automates the process of extracting sales data from MySQL, processing it with Pandas and generating daily visual reports with Matplotlib.
Data Pipeline
MySQL → Python → Pandas → Cleaning & Aggregation → Matplotlib → Automated Reports
Key Analysis
	•	Daily sales trends
	•	Category-wise sales
	•	Regional sales performance
	•	Top 5 products by sales
Automation
The project uses Python scheduling to run the reporting job daily and save generated charts as PNG files.
